# Identifier format

Stable names use:

```text
<variant>-<unique-id>
```

Rules:

- lowercase ASCII
- components separated with `-`
- punctuation removed from unique IDs
- the unique ID must originate from the target when possible

Examples:

```text
esp32-s3-7cdfa1123456
rp2040-e6616407e3398c2f
arduino-uno-r4-85735313331351f0
```

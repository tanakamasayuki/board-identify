# 識別子の形式

*[English](identifier-format.md) | [日本語](identifier-format.ja.md)*

安定した名前は次の形式です。

```text
<variant>-<unique-id>
```

規則:

- 小文字の ASCII
- 構成要素は `-` で区切る
- 固有 ID から記号類を取り除く
- 固有 ID は可能な限りターゲット自身に由来するものを使い、それができない場合はボード自身の USB シリアル番号を使う
- 6 文字未満の固有 ID は受け付けない
- 識別子はファイル名として使うため、`/` と NUL は決して含まれない

例:

```text
esp32-s3-7cdfa1123456
ch32x035c8t6-1ff9abcd880ebc48
wch-link-fc928f068181
rp2040-e6616407e3398c2f
arduino-uno-r4-wifi-34367333130351f0c1c1
```

## 1 つのポートに複数の名前

1 つのポートは複数の識別子で同時に公開されることがあり、具体的なものから順に並びます。WCH-Link デバッグプローブなら 2 つです。デバッグ端子の先にあるボード（工場出荷時に書き込まれた UUID から命名）と、プローブ自身（USB シリアル番号から命名）です。

```text
ch32x035c8t6-1ff9abcd880ebc48 -> /dev/ttyACM4
wch-link-fc928f068181         -> /dev/ttyACM4
```

前者はボードに追従し、どのプローブに差し替えても同じ名前になります。後者は何が接続されていてもプローブに留まり、何も接続されていなくても公開されます。「あのデバイス」と言うときにどちらを指しているかで選んでください。

## variant の出どころ

| 出どころ | variant | 固有 ID |
| --- | --- | --- |
| `esptool` | 報告されたチップ名（`esp32-s3` など） | eFuse MAC |
| WCH-Link の attach シグネチャ | 解決した型番 | 工場出荷時 UUID |
| WCH-Link のディスクリプタ | 意図的に粗い `wch-link` | プローブの USB シリアル |
| Arduino のボード定義 | ボードの `name` を正規化したもの | ボードの USB シリアル |

最後の 1 つはディスクリプタだけで完結する経路です。インストール済みの `boards.txt` が名乗る VID/PID をあらかじめ `arduino_ids` へ読み込んでいるので、固有の USB シリアル番号を報告するボードはポートを開かずに命名できます。`Arduino UNO R4 WiFi` は `arduino-uno-r4-wifi` になります。1 つのボードのスケッチ動作時とブートローダ動作時の組み合わせは同じ名前に落ちるので、書き込み中にリンク名が変わることはありません。

## variant の細かさ

variant はターゲットを特定できる範囲で細かくなります。WCH ターゲットでは attach シグネチャが、表に載っていれば型番まで解決し、載っていなければシリーズ名、さらに生のシグネチャへとフォールバックします。

| シグネチャ | variant |
| --- | --- |
| family `0x0d`、チップ ID `0x03510601` | `ch32x035c8t6` |
| family `0x0d`、チップ ID が表にない | `ch32x035` |
| どちらも表にない | `wch-0d-03510601` |

## 正規化

`normalize_component()` は NFKD 正規化を行い、それによって分離した結合文字を取り除いてから小文字化し、英数字以外の連続を 1 つの `-` に置き換えます。結合文字を取り除くことで、`Arduino Yún` は `arduino-y-n` に分割されず `arduino-yun` になります。`normalize_unique_id()` は英数字以外をすべて取り除いて小文字化します。いずれも使える文字が残らなければ `ValueError` を送出し、妥当な構成要素を作れなかったプローブは、疑わしい名前を公開せずにその識別結果を落とします。

| 入力 | 出力 |
| --- | --- |
| `ESP32-S3` | `esp32-s3` |
| `ESP32-C3 (QFN32)` | `esp32-c3-qfn32` |
| `CH32X035C8T6` | `ch32x035c8t6` |
| `Arduino Yún` | `arduino-yun` |
| `7C:DF:A1:12:34:56` | `7cdfa1123456` |
